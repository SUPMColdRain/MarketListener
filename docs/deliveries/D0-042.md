## 实现交付

**任务编号**：D0-042

**结果**：已实现已激活行情包的 `payload.sqlite` 读取、标的与周期选择、离线 Lightweight Charts K 线数据转换和中文导入状态；因没有真实 Provider 生产的已签名行情包，真实日线和分钟线的设备验收未通过也未被伪造。

**修改文件**：

- `android/app/src/main/java/com/marketmonitor/app/data/ImportedMarketData.kt`：读取激活包的标的、周期、bars JSON、来源和质量字段，生成 UI 所需的 K 线模型。

- `android/app/src/test/java/com/marketmonitor/app/data/ImportedMarketDataTest.kt`：覆盖 bar JSON 解码、时间、来源、质量和坏 JSON 拒绝。
- `android/app/src/main/assets/lightweight-charts.standalone.production.js`、`android/app/src/main/assets/THIRD_PARTY_NOTICES.md`：APK 内离线图表资产与通知。

**公开接口或数据变化**：无共享 Schema、数据库表或行情包格式变更。Android 内部新增只读 `ImportedMarketDataReader`，只消费已验证并原子激活的 `payload.sqlite`，不访问外部网络或 Provider 凭据。
