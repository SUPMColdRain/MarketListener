**任务编号**：D0-002

**结果**：定义版本 1 共享 JSON Schema，并由桌面端与 Android JVM 使用同一组合法和非法样本完成校验。

**修改文件**：

- `contracts/*.schema.json`：标准标的、Bar、Provider 运行结果、质量问题、市场包清单、策略包清单和策略结果契约。

- `tests/fixtures/contracts/`：共享合法/非法样本和案例索引。
- `desktop/src/market_monitor/contracts.py`、`desktop/tests/test_contracts.py`：Draft 2020-12 校验和 OHLC/时间顺序语义校验。
- `desktop/pyproject.toml`：新增 `jsonschema` 运行时依赖。
- `android/app/build.gradle.kts`、`android/app/src/test/java/com/marketmonitor/app/ContractValidationTest.kt`：共享测试资源和 Android JVM 校验。

**公开接口或数据变化**：

- 新增 7 个公开版本 1 JSON Schema；`schema_version` 均从 1 起。
- `bar.schema.json` 固定标的键、周期、交易日、开闭时间、时区、OHLCV、金额、持仓量、复权模式、来源、来源周期和质量状态字段。
- 市场包清单固定分区截止时间、文件字节数/行数/SHA-256、来源运行摘要和最低 App 版本。
- 策略结果固定策略/参数/数据版本、标的、信号时间、触发条件、观察理由、风险标签和运行状态。
- OHLC 边界与时间先后关系在桌面端和 Android 测试端采用等价语义校验；不改变 JSON Schema 规范本身。
