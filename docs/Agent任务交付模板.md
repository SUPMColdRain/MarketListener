**自检**：

- [ ] 已阅读 `ADR.md`、`CONTEXT.md` 和当前任务验收标准。
- [ ] 未提交凭据、私钥、个人数据或大体积行情。
- [ ] 未擅自改变架构、扩大范围或静默降级。
- [ ] 错误和外部阻塞没有被模拟数据掩盖。

## 代码审查交付

**审查任务**：<当前项目任务 ID>

**结论**：APPROVE / REQUEST CHANGES / BLOCKED

**发现**：按严重程度列出，每项必须包含文件和行号、可复现条件、影响以及建议修复方向。没有问题时明确写“未发现阻断问题”，并说明剩余测试缺口。

**重点检查**：

- [ ] 行为与当前任务验收标准一致。
- [ ] 没有越过 ADR 约束。
- [ ] 时间、交易日、来源和数据版本语义正确。
- [ ] 失败不会损坏个人数据或当前可用行情版本。
- [ ] 密钥和日志处理符合约束。
- [ ] 测试覆盖正常、边界和失败路径。
- [ ] 没有用模拟测试冒充真实数据源或真机验收。

## 修复回执

对每条审查发现逐项回答：已修复、不同意并给出证据、或暂缓并记录用户批准。修复后重新运行相关测试，由原审查 Agent 复核。
