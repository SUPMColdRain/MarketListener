# MarketListener 产业链全景图升级方案（产品与验收）

> 依据用户已批准的 ChatGPT 方案（Codex 产业链图谱开发）整理。执行基线以本文件 + ARCHITECTURE + TASK_QUEUE 为准。

## 1. 产品目标

把现有“研报知识库 + SVG 图谱”升级为：

> **专业券商/产业研究机构风格的产业链全景研报大图**：可搜索、可缩放、可展开、公司悬浮显示 F10、点击查看证据详情、能够自动更新、PC 与 Android 完全离线可用的交互式 HTML。

## 2. 视觉方向（非知识图谱）

禁止做成力导向图/蜘蛛网式节点连线。默认视图应为：

```text
                        新能源汽车产业链
┌──────────────────────── 上游 ────────────────────────┐
│  锂资源        正极材料        负极材料       电解液   │
│  [公司 公司]   [公司 公司 公司]  [公司 公司]  [公司]  │
└──────────────────────────────────────────────────────┘
                         ↓
┌──────────────────────── 中游 ────────────────────────┐
│  动力电池        电机电控        热管理       电驱系统 │
│  [公司 公司 公司] [公司 公司]     [公司]      [公司]  │
└──────────────────────────────────────────────────────┘
                         ↓
┌──────────────────────── 下游 ────────────────────────┐
│  乘用车        商用车        充换电         汽车服务   │
└──────────────────────────────────────────────────────┘
┌────────────────────── 配套支撑 ──────────────────────┐
│  充电桩 │ 换电 │ 回收 │ 车联网 │ 检测 │ 金融服务      │
└──────────────────────────────────────────────────────┘
```

设计原则：

- 浅灰白背景；上游青蓝、中游紫、下游粉/红、配套支撑灰绿等低饱和主题色。
- 大量白色/浅色卡片；环节间留足空间；少量粗箭头表达供应链方向。
- 公司名称小而密集，直接挂在对应环节/产品下。
- 不使用“程序员 Dashboard”风格；不把统计做成 KPI 大卡片。
- 链名称旁显示 A 股上市公司家数、港股上市公司家数。
- 深色主题作为可选切换。

## 3. 悬浮 F10 弹窗

鼠标/手指停在公司名称或代码上时显示：

| 字段 | 说明 |
| --- | --- |
| 公司名称 | 正式名称 |
| 证券代码 | A 股 6 位 / 港股 5 位 + 市场 |
| 公司地位或公司亮点 | 研报证据摘要（非 LLM 编造） |
| 总市值（更新日期） | F10 抓取值 + fetched_at |
| 流通市值（更新日期） | 同上 |
| 公司简介或介绍 | F10 来源 |
| 所属行业/证监会行业 | F10 来源 |
| 主营业务或经营范围 | F10 来源 |
| 最赚钱的业务或收入构成 | F10 来源；无数据则显示“暂无” |

## 4. 验收标准

1. `reports/industry/industry-atlas.html` 可 file:// 直接打开，无外部网络请求（无 CDN、无字体/图片外链）。
2. Atlas 展示口径 75 条链均可浏览（`chain_index.json` 原始 177 条子链待用户人工去重/归并）；每条链显示 A 股/港股上市公司计数。
3. 悬浮公司显示 F10 弹窗；没有可靠数据的字段明确显示“暂无”，不展示编造值。
4. 搜索能跨链命中公司/产品/原材料/环节并自动跳到对应链。
5. 缩放（PC 滚轮 + 移动端双指）可用。
6. PC `/industry-v2/` 可访问新版页面，`/industry/` 旧版仍可用。
7. Android 同步包包含 `industry/industry-atlas.html`，离线打开新版页面正常。
8. `pytest desktop/tests` 通过；Android `testDebugUnitTest` 通过。
9. 文档更新：STATUS.md、Plan.md、README 中产业链部分与本次升级保持一致。

## 5. 非目标（Never）

- 不重建第三套产业链数据库。
- 不删除已生成的 720 篇研报中间结果。
- 不无意义地重新解析已成功处理的 PDF。
- 不强制 SVG；SVG 仅可作局部可选工具。
- 不创建与 `industry_graph` 平行的新产业链数据库（F10 底表是“企业定位层”，不是产业链知识层）。
- 不允许运行时联网请求；页面必须完全离线。
- 不编造公司信息。
