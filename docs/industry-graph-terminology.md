# 产业链图谱术语文档（FULL-700）

日期：2026-08-06
状态：实现交付（等待系列统一审查）

本文件固化产业链图谱领域的统一业务语言。任何实现、测试、数据库字段和
界面文案都必须使用这里的定义；出现术语歧义时，先按本表消歧，无法消歧的
关系必须进入 `PENDING`（待人工确认），不允许静默选择。

## 实体类型

| 类型 | 定义 | 示例 |
|---|---|---|
| COMPANY | 依法注册、以营利为目的的法人主体 | 贵州茅台酒股份有限公司 |
| PRODUCT | 公司生产或销售的可辨识产品或服务形态 | 茅台酒、动力电池 |
| INDUSTRY | 由同类产品或服务构成的市场/行业分类 | 白酒、半导体 |
| SUPPLIER | 在特定关系中向上游提供原材料、零部件或服务的实体角色 | 包材供应商 |
| CUSTOMER | 在特定关系中向下游购买产品或服务的实体角色 | 经销商 |
| RAW_MATERIAL | 用于生产过程的原材料或资源 | 碳酸锂、铜箔 |
| SERVICE | 不形成实物产品的交付物 | 晶圆代工、物流 |
| REGION | 地理区域或行政区域 | 华东地区 |

## 关系类型

| 类型 | 定义 | 方向 |
|---|---|---|
| SUPPLIES | A 向 B 供应原材料/零部件/服务 | A -> B |
| PURCHASES | A 从 B 采购原材料/零部件/服务 | A -> B |
| PRODUCES | A 生产产品 B | 公司 -> 产品 |
| PART_OF | B 是 A 的组成部分，或 A 属于 B | 部分 -> 整体 |
| COMPETES_WITH | A 与 B 存在竞争关系 | 无向 |
| DISTRIBUTES | A 分销/代理 B 的产品 | A -> B |
| USES | A 使用 B 的产品/服务 | A -> B |
| OWNS | A 持有/控制 B | A -> B |
| CUSTOMER_OF | A 是 B 的客户 | A -> B（等价于 B SUPPLIES A） |

## 确认状态

| 状态 | 含义 |
|---|---|
| PENDING | 自动管线产出但未达到自动接受阈值，等待人工确认 |
| AUTO_ACCEPTED | 置信度 >= 0.8 且有证据，由自动管线接受 |
| HUMAN_CONFIRMED | 人工确认通过，自动管线不得覆盖 |
| REJECTED | 人工或审计判定为错误 |
| SUPERSEDED | 已被修订版本取代，保留历史供审计追溯 |

## 证据定位

每条证据必须记录原始来源、解析版本和精确定位：

- HTML：DOM 路径（如 `html/body/table[1]/tr[2]/td[1]`）。
- Excel：工作表与单元格（如 `Sheet1!B2`）。
- PDF：页码 + 行号（+ 可选的列内偏移）。
- 公告/纯文本：行号（+ 偏移）或页码。

解析版本使用 `主.次.修订` 三段式；同一来源文件的同一解析版本重复导入必须
幂等返回已有证据，不产生重复行。

| 白酒 | 行业分类而非具体产品 |

固定样本由 `desktop/tests/test_industry_graph_models.py` 强制校验：同一提及
在术语表中只能映射一个实体类型；缺失或冲突映射视为术语缺陷并失败。
